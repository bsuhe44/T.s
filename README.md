# SIWANKURDSH

پنل مدیریت پروکسی تلگرام (MTProto با Fake-TLS) با امکان ساخت کاربر، تعیین حجم، تاریخ انقضا و محدودیت اتصال همزمان.

## نصب (Ubuntu / Debian، با دسترسی root)

    unzip siwankurdsh.zip && cd siwankurdsh
    sudo bash install.sh

نصب‌کننده نام کاربری و رمز ادمین، آی‌پی یا دامنه سرور، پورت پروکسی (پیش‌فرض 443) و پورت پنل (پیش‌فرض 8080) را می‌پرسد.
بعد از نصب: http://IP:8080

## نحوه کار
- هر کاربر یک secret مخصوص خودش دارد و لینک اتصال (tg://proxy و t.me) برایش ساخته می‌شود.
- پنل هر ۱۵ ثانیه مصرف را از پروکسی می‌خواند. کاربری که حجمش تمام شود یا منقضی شود از تنظیمات پروکسی حذف می‌شود.
- با هر تغییر در فهرست کاربران مجاز، پروکسی ری‌استارت می‌شود و اتصال‌های باز لحظه‌ای قطع و دوباره وصل می‌شوند.

## نکات امنیتی
- پنل به‌صورت پیش‌فرض HTTP است. برای امنیت بیشتر پشت Nginx با HTTPS بگذارید یا فقط با SSH tunnel بازش کنید.
- رمز ادمین در /opt/siwankurdsh/.env ذخیره می‌شود. برای تغییر، فایل را ویرایش و `systemctl restart siwankurdsh` بزنید.

## دستورات مفید
    systemctl status siwankurdsh mtprotoproxy
    journalctl -u siwankurdsh -f
